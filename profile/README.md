# 👕 프로젝트 : AID-Fit (Intelligent Fashion Agent)

**"사용자의 스타일을 '보고' 맥락을 '이해'하여 최적의 코디를 '제안'하는 지능형 패션 에이전트"**

---

## 1. 프로젝트 배경 및 개요
### 1.1 배경 (Background)
* **기존 시스템의 한계:** 현재 대부분의 의류 추천 서비스는 단순 키워드 검색이나 과거 구매 이력 기반의 필터링에 의존하여, 사용자의 현재 스타일이나 구체적인 상황(TPO)을 반영하기 어렵습니다.
* **기술적 기회:** LLM의 발전으로 자연어 이해도가 높아졌으며, VLM(Vision-Language Model)을 통해 이미지의 시각적 맥락을 텍스트화할 수 있게 되었습니다. 이를 결합하면 '사람 같은' 패션 어드바이스가 가능해집니다.

### 1.2 개요 (Overview)
**AID-Fit**은 사용자가 업로드한 의류 사진과 텍스트 요구사항을 분석하여, 기존 의류 DB에서 가장 잘 어울리는 상품을 찾아 코디해주는 **Agentic AI 기반 추천 시스템**입니다.

---

## 2. 프로젝트 목표 (Goals)
1.  **시각적 맥락 파악:** VLM을 활용하여 사용자의 의류 스타일(색상, 소재, 핏, 무드)을 정밀하게 추출합니다.
2.  **지능형 지식 검색:** RAG 시스템을 통해 방대한 의류 데이터셋에서 사용자 요구에 부합하는 아이템을 실시간으로 검색합니다.
3.  **자율적 의사결정:** Agentic AI 구조를 채택하여 단순 추천을 넘어 추천의 '이유'와 '코디 법'까지 자연어로 생성합니다.
4.  **확장성 있는 아키텍처:** 3개월 내에 MVP(최소 기능 제품)를 구현하고 향후 데이터 확장이 용이한 구조를 설계합니다.

---

## 3. 핵심 기능 (Core Features)
| 단계 | 기능명 | 설명 |
| :--- | :--- | :--- |
| **01** | **멀티모달 입력** | 사용자의 텍스트 요구사항과 기준 의류 이미지 동시 수용 |
| **02** | **VLM 스타일 분석** | 이미지에서 시각적 특징(오버핏, 코튼, 화이트 등)을 텍스트 데이터로 변환 |
| **03** | **RAG 기반 시맨틱 검색** | 분석된 스타일과 사용자 의도를 결합해 Vector DB에서 유사 상품 추출 |
| **04** | **에이전트 추론** | 검색된 정보를 바탕으로 TPO에 맞는 코디 논리를 구성 및 환각 방지 제어 |
| **05** | **맞춤형 코디 제안** | 최종 추천 상품 정보와 함께 개인화된 스타일링 가이드 출력 |

## 4. 팀원 역할 분담 (Role Assignment)

| 이름/역할 | 주요 책임 (Responsibilities) | 핵심 작업 (Tasks) |
| :--- | :--- | :--- |
| **Member A**<br>(에이전트/백엔드) | **전체 파이프라인 통합 및 에이전트 설계** | LangChain/LangGraph 구축, API 서버 개발, 프롬프트 엔지니어링 |
| **Member B**<br>(RAG/데이터) | **지식 베이스 및 검색 시스템 구축** | 의류 데이터셋 확보, Vector DB(ChromaDB 등) 구축, 검색 최적화 |
| **Member C**<br>(비전/VLM) | **시각 데이터 분석 및 정형화** | VLM(GPT-4o/Gemini) 프롬프트 최적화, 이미지 특징 추출 로직 개발 |
| **Member D**<br>(FE/UX) | **사용자 인터페이스 및 결과 시각화** | React/Flutter/React-Native 기반 UI 개발, 이미지 업로드 및 채팅 인터페이스 구현 |

## 5. 3개월 핵심 마일스톤 (Roadmap)

### **1개월 차: 기초 구축 및 기술 검증 (PoC)**
- 프로젝트 환경 설정 및 협업 툴(Git, Notion) 세팅
- 의류 데이터셋 확보 및 Vector DB 초기 설계
- VLM 및 LLM API 연동 테스트 및 성능 벤치마킹
- UI 와이어프레임 확정

### **2개월 차: 핵심 로직 구현 (MVP)**
- VLM-RAG-LLM 파이프라인 단일 흐름 연결
- 이미지 특징 추출 프롬프트 고도화 및 JSON 파싱 자동화
- 백엔드 API 서버와 프론트엔드 연동
- 에이전트 도구(Tool) 호출 및 라우팅 로직 구현

### **3개월 차: 고도화 및 최종 결과물 도출**
- 추천 결과의 정확도 향상을 위한 리랭킹(Re-ranking) 적용
- 예외 상황(이미지 분석 실패 등) 처리 및 시스템 안정화
- 최종 UI 디자인 입히기 및 성능 최적화(응답 속도 개선)
- 최종 시연 영상 제작 및 프로젝트 문서화 마무리
