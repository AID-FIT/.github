# 의류 추천 시스템
## 🔄 추천 시스템 파이프라인 구현 과정
> 1️⃣ User Query (사용자 입력 단계)

동작: 사용자가 텍스트 요구사항과 기준이 되는 의류 사진(이미지)을 동시에 시스템에 전달합니다.
예시: * Text: "벚꽃 보러 갈 건데 이 셔츠랑 입을 바지 찾아줘"
Image: user_shirt_01.jpg (오버핏 화이트 셔츠)
> 2️⃣ VLM (시각/언어 분석 단계)

동작: 에이전트가 VLM(Vision-Language Model) 도구를 호출하여, 업로드된 이미지를 컴퓨터와 LLM이 이해할 수 있는 '상세한 텍스트(Context)'로 번역합니다.
기술적 처리: VLM이 사진에서 색상, 소재, 핏, 무드(Mood) 등의 시각적 특징을 추출합니다.
결과물: "오버핏, 면 소재, 화이트 컬러, 캐주얼/미니멀 스타일의 셔츠"
> 3️⃣ RAG (유사 의류 검색 단계)

동작: 에이전트가 VLM의 분석 결과와 사용자의 텍스트(벚꽃, 바지)를 결합하여 Vector DB에서 가장 적합한 옷을 찾아옵니다.
기술적 처리: 1. 검색어를 임베딩 모델을 통해 고차원 벡터(숫자 배열)로 변환합니다.
2. Vector DB(사전에 크롤링된 쇼핑몰 의류 데이터가 저장된 곳)에서 코사인 유사도(Cosine Similarity)를 계산하여 가장 가까운 상품 Top-K개를 추출합니다.
결과물: DB에서 찾은 상품 정보 (예: [ID:102, 연청 와이드 데님 팬츠, 봄 시즌용], [ID:205, 베이지 코튼 슬랙스])
> 4️⃣ LLM (최종 추론 및 답변 생성 단계)

동작: 에이전트의 '두뇌'인 LLM이 지금까지 수집된 모든 정보(사용자 의도 + VLM 분석 내용 + RAG 검색 결과)를 종합하여 추천 논리를 구성합니다.
기술적 처리: LangChain 프롬프트를 통해 주어진 RAG 데이터 내에서만 답변을 생성하도록 제어(환각 현상 방지)하고, 사용자의 TPO(벚꽃, 데이트)에 맞는 자연스러운 텍스트를 생성합니다.
> 5️⃣ Recommend (맞춤형 코디 제안 단계)

동작: 최종적으로 포맷팅된 추천 결과를 사용자 화면에 출력합니다.
최종 출력 예시: "업로드해주신 화이트 셔츠는 오버핏의 미니멀한 스타일이네요! 벚꽃 구경을 가신다면 화사한 느낌을 줄 수 있도록, 저희 DB에서 찾은 **[연청 와이드 데님 팬츠]**를 매치하는 것을 추천해 드립니다. 활동하기도 편하고 봄 날씨에 아주 잘 어울릴 거예요."
